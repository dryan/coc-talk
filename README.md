# Good Conduct: How Django Modernized its Code of Conduct

Slide deck for a talk at DjangoCon US 2026, presented by [Dan Ryan](https://dryan.com).

It's a static HTML/CSS/JS slideshow — no build step, no framework, just open `index.html`.

## Files

- `index.html` — the slides
- `styles.css` — fonts, fluid type scale, slideshow layout
- `slideshow.js` — keyboard navigation web component
- `normalize.css` — third-party CSS reset
- `speaker-notes.md` — presenter notes, not shown on slides
